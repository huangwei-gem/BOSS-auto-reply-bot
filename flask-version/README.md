# BOSS 自动回复机器人 - Flask 版本

## 安装

```bash
pip install flask DrissionPage openai
```

## 使用

### 1. 设置环境变量（AI API Key）
```bash
set AI_API_KEY_1=sk-xxxxx
set AI_API_KEY_2=sk-xxxxx
```

### 2. 启动 Web 界面
```bash
cd flask-version
python app.py
```

### 3. 打开浏览器访问
```
http://127.0.0.1:5000
```

## 功能

- 📊 实时状态监控（运行状态、回复数、简历数）
- 📋 未读消息列表查看
- 📜 实时操作日志
- ▶️ 一键启动/停止机器人
- ⚙️ 配置和规则查看

## 界面说明

| 区域 | 说明 |
|------|------|
| 顶部状态 | 显示机器人运行/停止状态 |
| 统计卡片 | 已回复数、已发简历数、上次检查时间、当前处理 |
| 控制按钮 | 启动/停止/刷新未读 |
| 未读消息 | 显示所有未读会话的名称和预览 |
| 操作日志 | 实时显示机器人的操作记录 |
| 配置信息 | 检查间隔、每小时上限、规则数量 |
| 回复规则 | 关键词 -> 回复内容的映射表 |
